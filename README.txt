# MISJA.GG — strona zbiórek

## Pliki
- `index.html` — struktura strony.
- `style.css` — wygląd, responsywność i animacje.
- `script.js` — wybór zbiórki, kwoty orientacyjne, kopiowanie linków i udostępnianie.

## Publikacja na GitHub Pages
1. Wgraj wszystkie trzy pliki do głównego katalogu repozytorium.
2. Upewnij się, że nazwy plików są dokładnie takie jak wyżej.
3. Otwórz **Settings → Pages**.
4. W sekcji Build and deployment wybierz **Deploy from a branch**, gałąź `main` i katalog `/ (root)`, a następnie zapisz.
5. Po opublikowaniu otwórz adres GitHub Pages repozytorium.
